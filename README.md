## 문답
> 3 Layer Architecture(Controller, Service, Repository)를 적절히 적용했는지 확인해 보고, 왜 이러한 구조가 필요한지 작성해 주세요.
> > `각 사용처에서 Controller, Service, Repository를 적절히 적용했습니다.
이러한 구조를 사용하는 이유는 각 객체마다 역할을 분리해서 사용해 유지보수성, 확장성에 용이하기 때문에 사용하게 됩니다.`

> 엔티티를 그대로 응답하지 않고 DTO로 바꿔서 응답하는 이유는 무엇인가요?
> > `Entity를 그대로 응답하게 되면 View의 요구 정보가 바뀌게 될 경우 엔티티를 수정해야하는 경우가 생기게 됩니다.
DTO로 바꿔서 응답하게 되면, Entity를 노출하지 않고 보호할 수 있고, 필요한 데이터들을 선별할 수 있게 됩니다.
그리고, validation 코드와 모델 코드를 분리시켜 각 로직에 집중되도록 구현할 수 있게 됩니다.`

> Bean Validation이 필요한 이유에 대해 작성해 주세요.
> > `Bean Validation을 사용하게 되면 따로 검증 코드를 일일이 반복해서 작성하지 않을 수 있고, 어노테이션 기반으로 선언해 검증이 가능합니다.`
